# Elara — Fine Jewelry

A modern, elegant web experience for Elara, showcasing curated fine jewelry collections, artisanal craftsmanship, and bespoke inquiries.

## Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite 8
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development
Start the development server:
```bash
npm run dev
```

### Production Build
Build the project for production:
```bash
npm run build
```

### Preview
Preview the production build locally:
```bash
npm run preview
```

## Deployment

This project is optimized for deployment on [Vercel](https://vercel.com).
- **Framework Preset:** Vite
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Install Command:** `npm install`
